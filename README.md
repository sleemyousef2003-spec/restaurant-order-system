# Restaurant Order Management System

## Project Description
The Restaurant Order Management System is a Python-based console application designed to help restaurant staff manage customer orders efficiently. The system allows users to place orders, customize items, remove items, and generate a final bill automatically.

## Features
- Display restaurant menu with prices
- Place customer orders
- Add customization notes for items
- Remove the last ordered item
- View current order list
- Calculate total bill and item count
- Print formatted bill summary
- Admin menu management:
  - Add menu items
  - Update prices
  - Delete menu items

## Data Structures Used
- **Dictionary:** Used to store menu items and prices
- **List:** Used to store customer orders
- **Tuple:** Used to return bill summary values

## String Operations
The project uses:
- `strip()`
- `title()`
- `replace()`

to clean and format user input.
